## Descripción

En esta carpeta se encuentra el trabajo de recuperación de la Unidad I. Incluye el cuestionario teórico, evidencias del portafolio web y las pruebas realizadas.

## Tecnologías utilizadas

- HTML para la estructura de la página.
- CSS para los estilos, el diseño adaptable y el efecto parallax.
- JavaScript para la interacción de las competencias.
- Git y GitHub para el control de versiones.

## Actividades realizadas

- Agregué la sección de trayectoria educativa con tarjetas.
- Incorporé un fondo con efecto parallax y ajustes para dispositivos móviles.
- Añadí la sección de competencias adquiridas con botones para mostrar y ocultar información.
- Respondí el cuestionario teórico de la unidad.
- Realicé pruebas de visualización e interacción en el navegador.

## Archivos

- `respuestas_unidad1.pdf`: cuestionario teórico resuelto.
- `cuestionario/`: archivo fuente del cuestionario.
- `evidencias/`: capturas de pantalla del trabajo realizado.

## Pruebas

- Verifiqué que las secciones de educación y competencias aparezcan en la página.
- Probé los botones de mostrar y ocultar información.
- Revisé la visualización de la página en el navegador.
